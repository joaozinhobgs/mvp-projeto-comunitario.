MVP — Projeto Comunitário

Sobre o projeto

Este projeto tem como objetivo desenvolver um sistema simples para ajudar a solucionar um problema identificado em uma comunidade.

Objetivo

Criar uma solução digital acessível, prática e fácil de utilizar, contribuindo para melhorar a organização das atividades e facilitar o acesso às informações.

Público-alvo

Pessoas atendidas pelo parceiro comunitário envolvido no projeto.
